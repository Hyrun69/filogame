# O Labirinto da Verdade

### Sobre o projeto
Este é um jogo de escolhas focado em conceitos de justiça e sociedade. A experiência foi baseada na teoria do "Véu da Ignorância" do filósofo John Rawls. O desafio é estruturar uma sociedade ideal sem saber qual será a sua posição nela.

### Tecnologias utilizadas
*   HTML e CSS: Estrutura e design visual do site.
*   JavaScript: Lógica das escolhas e interatividade do jogo.
*   GitHub Pages: Alojamento e publicação do projeto na internet.

### Aprendizados técnicos
*   Publicação de projetos: Processo completo de colocar um site online.
*   Resolução de problemas: Correção de erros de rotas e caminhos de ficheiros (erro 404).
*   Organização de código: Gestão de ficheiros para garantir o funcionamento estável do sistema.
